# UTS Business Intelligence (Streamlit)
1. `pip install -r requirements.txt`
2. Edit data diri di blok PROFILE pada `app.py` (atau lewat sidebar → Edit Profil)
3. Taruh foto sebagai `foto_profil.jpg` di folder ini (atau upload lewat Edit Profil)
4. `streamlit run app.py`
Login demo: admin / uts2026  (ubah LOGIN_USER, LOGIN_PASS di app.py)
